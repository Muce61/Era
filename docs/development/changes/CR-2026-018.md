## Mandatory stop

Exact Compare stopped before examining the 61,776-partition stream with:

`ContractViolation: V2 receipts are not bound to the approved legacy hash algorithm`

The failure is an implementation wiring defect: V2 Receipts correctly bind the uppercase receipt
marker `ERA_CANONICAL_JSON_ROW_V1`, while the comparator's algorithm authority is the lowercase
`era-canonical-json-row-v1`. `ProductionRuntimeV2Backend.compare_run_a()` passes the uppercase
receipt marker into the comparator argument that explicitly requires the lowercase algorithm
authority. Unit tests cover the comparator with the correct lowercase value but mock the
production call boundary, so they did not detect the wrong production keyword argument.

No comparison report was written, no sealed input was modified, and no comparison was bypassed.
S2-T10 and Group 1 remain NOT PASS. The candidate correction and any comparison retry require
separate approval under CR-2026-019.
