## Blocking evidence

Run `stage2-g1-v2-b-20260719T045142Z-0eeb27e0be21` completed both Foundation Tasks and eight
BTCUSDT Group-1 PRICE owner months, then was stopped by the user while processing 2020-09-11. Its
checkpoint is `INTERRUPTED_RECOVERABLE`, revision 6, with no failure, no publication and no active
process. The run remains immutable evidence and may not be resumed with changed code or adopted as
Group-1 input.

The approved profile identified duplicate previous/current processing-day work, repeated reads of
overlapping Foundation fragments, ineffective ThreadPool parallelism, small legacy-hash runs and
daily Parquet rereads. These are execution defects only; no research or output semantic change is
approved.

## Approved correction

1. Calculate every processing day once, persist a write-once candidate-attempt cache and finalize
   each owner day from its current and previous processing-day receipts.
2. Reuse already verified Contract Price, causal-bar and Trades-primitive fragments through bounded
   instrument-local sliding caches.
3. Use a spawn-safe three-process month executor. Workers write isolated staging and the parent
   validates and commits results in deterministic manifest order.
4. Preserve every formal row and compatibility Hash while batching canonical row encoding, using
   larger deterministic external-sort runs and streaming Arrow batches to monthly writers.
5. Treat SIGINT, KeyboardInterrupt and approved user stops as `INTERRUPTED_RECOVERABLE`, with
   append-only stop evidence and no automatic continuation.
6. Add a local read-only Web progress service backed by atomic `progress-v2.json` evidence.
7. Performance objectives are promotion gates, not integrity failures. A miss records
   `PERFORMANCE_OBJECTIVE_NOT_MET` and blocks a new Authority/full run without invalidating data.
8. After correctness, performance and repository gates pass, supersede the stopped run by receipt,
   freeze a new Authority twice, copy only fully verified Foundation artifacts into a new run and
   rebuild all Group-1 output from scratch.
