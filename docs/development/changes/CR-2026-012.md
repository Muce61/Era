## Blocking evidence

Replacement Run B `stage2-g1-v2-b-20260718T105814Z-cb5c25abd485` completed all 316 BTC
monthly Foundation checkpoints and all 82 BTC packed checkpoints, then failed before Task evidence
was sealed. The backend compared process-lifetime `ru_maxrss` (`2,222,686,208` bytes) with a
baseline captured at process startup (`100,876,288` bytes) and treated the resulting
`2,121,809,920` byte lifetime peak delta as if it were a seal-phase current-memory delta. The run
is terminal `FAILED_UNPUBLISHED`, has no completed Task receipt and published no object.

`ru_maxrss` is monotonic process-lifetime audit state and cannot be reset after source tables are
released. The failure therefore does not establish that seal current RSS exceeded the approved
3 GiB limit. It is a resource-measurement contract defect, not a Stage 1, research-semantic,
identity, payload or deterministic-result defect.

## Approved correction

1. Preserve the 1 GiB Arrow inflight hard limit.
2. Preserve the 3 GiB absolute current-RSS hard limit.
3. Retain lifetime `ru_maxrss` as audit evidence only; never treat its process-start delta as a
   phase-local hard failure.
4. Use a phase-current baseline and a continuously sampled current-RSS delta hard limit. The
   calibrated limit remains 1 GiB; real packed-object scanning and Task sealing observed less
   than 0.4 GiB phase-current delta.
5. Record baseline current RSS, sampled current maximum, lifetime peak, Arrow maximum and phase
   name for monthly build, packing and Task sealing.
6. Run red/green, real packing/seal profiles, determinism and all quality gates before a new
   Authority freeze.
7. Permanently retain and invalidate the failed Run B. It may not be resumed, reused, published,
   cleaned or assigned another meaning.
8. After validation, freeze one final-code Authority and execute exactly one new replacement Run
   B. It must build 80,784 V2 partitions and compare all 61,776 Group-1 partitions to Run A.

This correction may not change Stage 1, Run A, Preregistration, config hash, research parameters,
event definitions, candidate identity, MarketEpisode identity, payload hash or comparison rules.
S2-T11 through S2-T20 remain DRAFT and unexecuted.
