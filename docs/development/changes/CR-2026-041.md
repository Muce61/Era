## Problem

The Plan v1.3 supervisor and command adapters existed, but the historical Plan v1.2 producers
still selected accepted Run and Snapshot IDs through module constants. An output Hash alone cannot
locate or validate an upstream artifact, and the adapter DAG incorrectly made S2P13-T14 depend on
S2P13-T13 instead of the shared S2P13-T12 path output.

## Decision

- Preserve every Plan v1.2 CLI and sealed artifact as historical evidence.
- Introduce a versioned, fully qualified Plan v1.3 source-binding and producer-receipt contract.
- Require successor producers to receive complete upstream handoffs and reject legacy aliases,
  hard-coded accepted Run IDs, unqualified Task IDs, symlinks and Hash drift.
- S2P13-T12 binds S2P13-T11 PASS as an execution prerequisite but continues to derive raw paths
  only from immutable S2-T10 evidence. Lifecycle result rows must not contaminate event paths.
- S2P13-T13 and S2P13-T14 both consume S2P13-T12. They are data-independent siblings.
- S2P13-T15 consumes S2P13-T14. S2P13-T16 consumes S2P13-T11, S2P13-T13, S2P13-T15 and the
  frozen S2P13-T20 preregistration.
- Split preflight into a static all-task gate and a per-task upstream-input gate.
- Use the same producer core and schemas for isolated seven-day rehearsal and formal execution.
  Rehearsal evidence IDs must never be represented as formal Run IDs.

The applicable rules are `EVENT-CONSUME-MARKET-EPISODE`,
`STRATEGY-V1-PRICE-ONLY-HISTORICAL`, `DATA-HISTORICAL-NO-FAKE-EXECUTION` and
`EXEC-EXIT-COORDINATOR-ONLY`.

## Acceptance

All six producers must consume the exact approved successor handoff, serialize and strictly read
back their outputs, reconcile counts and independently Verify. The final committed code must then
pass a real-input rehearsal over `[2020-01-01, 2020-01-08)` through S2P13-T16 and the read-only UI.
Any repair invalidates that rehearsal and requires a complete restart.

During implementation, OQ-S2-012 was opened because the lifecycle producer has no approved source
for protection/structure exits and lacks three related deterministic replay choices. The v2
handoff may be stabilized and tested, but production expansion and the final rehearsal stop until
that OQ is resolved.
