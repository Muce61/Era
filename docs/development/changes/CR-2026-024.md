## Trigger

requires a new Task version before adding a formal full-data CLI. The current progress service and
HTML stop at S2-T13 and cannot automatically display S2-T14 evidence. Continuing now would invent
an unapproved publication contract or hard-code a UI result.

- `src/era100x/research/stage_2/labels/ambiguity/full_run.py`;

No T13 source/output mutation, S2-T15+ implementation, Stage 1 change or Stage 3 path is added.

## Contract to freeze before execution

1. Bind the accepted S2-T13 Authority, Run, Snapshot, Manifest, Catalog, output hashes, counts and
   code commit before creating an S2-T14 Run ID.
2. Read all 31,962,480 classifications without rewriting them. Aggregate separately by BTC/ETH,
   H1/H2, timing, target and stop; preserve raw label and ambiguity-reason distributions.
3. Publish Primary failure-treated rate, conditional rate excluding AMBIGUOUS and theoretical upper
   rate treating AMBIGUOUS as success. Only Primary may feed later Go/No-Go.
4. H1 same-event ambiguity reports adverse/optimistic path bounds. Other source ambiguity never
   invents a path order. H2 determinate rows remain determinate under frozen V2 order.
5. Publish only compact distributions and audit bindings; do not duplicate 31,962,480 row-level
   classifications. Verify must still scan the complete immutable S2-T13 source and recompute every
   aggregate deterministically.
6. Use append-only Authority/Run/Manifest/Catalog/failure evidence and atomic publication. The UI
   derives status from the newest valid combined evidence and raw HTML never presets PASSED.
7. Stage 3 remains locked. No UI control may run, resume, publish, delete or mutate evidence.
