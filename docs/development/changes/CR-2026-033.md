## 目标

在研究框架中增加 `SPECIAL_RESEARCH_POINT`（特异研究点）。它允许研究者为了发现新现象，
明确声明某些既有研究规则在该研究点内不适用。没有被逐条声明豁免的规则继续完整适用，
不得通过“自由研究”“实验模式”或空清单产生隐式全局放宽。

特异研究点只产生隔离的探索性证据，不是新的正式策略、Authority、Task PASS、Stage PASS、
H3/F1结论或实盘授权。

## 默认继承语义

1. 读取并绑定完整规则注册表及其Hash。
2. 默认所有规则仍然有效。
3. 只从有效规则集合中减去 `declared_exemptions` 明确列出的规则。
4. 未知rule_id、重复豁免、空原因、规则注册表Hash漂移或豁免范围不清楚时硬失败。
5. 每次运行和报告必须同时保存：完整规则集合、已豁免规则、仍生效规则及其Hash。
6. 新规则加入注册表后自动生效；旧特异研究点不得因为旧Manifest未列出新规则而自动豁免。

因此，声明“不受A、B限制”只会关闭A、B；C、D及以后新增的规则仍然继续执行。

## 每条例外必须声明

每个 `DeclaredResearchExemption` 至少包含：

- `rule_id`；
- `rule_status` 和冻结来源Hash；
- 不适用的精确研究阶段、数据、指标、函数和时间范围；
- 研究理由与要检验的问题；
- 可能产生的偏差、风险和不可解释范围；
- 替代控制或隔离措施；
- 人工批准引用；
- 到期条件和失效条件。

“不受所有规则限制”“其余同理”“按需要放宽”以及通配符均非法。

## 可豁免范围提案

在不修改V1.3.4手册的前提下，只允许以下研究所有者规则进入显式豁免候选：

- `EVENT-CONSUME-MARKET-EPISODE`：探索不同事件定义；
- `RESEARCH-LOCKED-REPLAY-ONCE`：允许明确标记的迭代探索，但结果不得充当锁定回放；
- `STRATEGY-V1-PRICE-ONLY-HISTORICAL`：只可使用已有真实历史能力探索Trades/Flow等变体，
  仍禁止伪造Bid/Ask、延迟、部分成交或滑点；
- `RESEARCH-H3-CONDITIONAL-ROUND-PROB`：可探索替代研究指标，但不得描述成真实实盘概率。

由于这些正式rule_id当前均为FROZEN，每一个具体特异研究点仍必须获得人工批准。批准本CR只
批准框架，不预先批准任何未来豁免。

Task、ADR或预注册中的BASELINE/RESEARCH约束也可成为候选，但必须使用稳定的
`constraint_id + source_hash`，不得用自然语言模糊匹配。

## 永不可豁免底线

特异研究点不能豁免或绕过：

- 历史事实真实性、`DATA-HISTORICAL-NO-FAKE-EXECUTION`和证据等级；
- Stage 1及T10～T14等密封输入的只读、Hash、lineage和append-only要求；
- 禁止真实API、testnet、真实资金、自动下单或把研究结果连接到执行端；
- 执行、风险、状态机、会计、平仓、ROUND及`ExitCoordinator`规则；
- Stage/Task人工批准门、Stage 3锁、开放问题阻塞和七天短跑门；
- DEPRECATED行为不得恢复；
- `BLOCKED_BY_FORWARD_VALIDATION`不得被研究点提升成已验证或可实盘；
- 禁止把H1/H2/H3描述成真实收益、真实成交或无条件实盘概率；
- 失败、豁免、尝试和结果的完整审计留痕。

这些是研究隔离和事实真实性规则，不是策略参数。若要改变，必须先修改唯一权威手册，不能
由本框架或单个研究点完成。

## 输出与消费隔离

特异研究点输出强制标记：

- `evidence_class = EXPLORATORY_NONCOMPLIANT`；
- `formal_stage_evidence = false`；
- `eligible_for_authority = false`；
- `eligible_for_task_pass = false`；
- `eligible_for_stage_gate = false`；
- `live_or_testnet_authorized = false`。

正式pipeline、Web UI PASS投影和后续Stage消费者必须拒绝这些输出。报告必须显著展示所有
豁免规则，不能只显示研究结果。

如果探索结果值得进入正式研究，必须创建新的CR/ADR/Task版本，重新预注册并在完整规则下
独立复验；不得把特异研究点的输出原地升级。

## 建议实现

批准后最小实现范围：

- 在 `src/era100x/research/stage_2/manifests/` 增加
  `SpecialResearchPointManifest`、`DeclaredResearchExemption`和规则解析器；
- 读取 `configs/rules/v1.3.4.yaml`，绑定注册表Hash并计算
  `effective_rule_ids = all_rule_ids - declared_exempt_rule_ids`；
- 对候选规则所有者、状态、人工批准、不可豁免清单、未知/重复/通配符执行fail-closed校验；
- append-only发布研究点Manifest；
- 只在隔离未发布根运行；
- Web UI若未来接入，必须显示`特异研究 / 非正式证据`和完整豁免清单，永不投射Task PASS。

## 必须测试

- 空豁免清单：全部规则继续有效；
- 声明一个规则：只有该规则被移除；
- 未声明规则和后来新增规则自动继续生效；
- 未知、重复、通配符、空理由、Hash漂移硬失败；
- 不可豁免规则硬失败；
- research-owner FROZEN规则没有具体人工批准时硬失败；
- 相同输入生成相同Manifest Hash；
- 输出不能被正式Authority、Task PASS或UI PASS消费；
- 无网络、账户、订单、Stage 3或密封数据写入。
