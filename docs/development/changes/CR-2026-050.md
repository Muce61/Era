## 决定

批准在不改动历史密封证据的前提下建立 Stage 2 successor 证据链：

1. T11 同时产出只读 canonical Trades 对照轨和 Contract Price OHLC 生命周期主轨；
2. OHLC 只解决 Trade 缺口秒内“是否越界”的粗粒度边界问题，不声称成交或秒内顺序；
3. T11、T16 只做等价性能重构，正式门均为至少 `2×` 且峰值 RSS 不超过 `3 GiB`；
4. T11–T20 必须完整重跑，新 Authority、新 Run、新 Manifest，旧失败保持不可变；
5. H2 Primary 的 BTC/T2/20bp/25bp、matching、AMBIGUOUS 和 cluster 合同不变。

本 CR 授权代码、测试、来源审计、隔离 rehearsal 与性能验证。正式全量 Run 仍须在干净
commit 冻结后获得单独、绑定该 commit 的人工批准。Stage 3 与移动止损研究保持锁定。

2026-07-29 addendum：批准补齐 Plan v1.8 的正式 approval、Authority、十 Task DAG
runner、append-only checkpoint、Catalog、Manifest、reconcile、候选发布与 Verify 编排。
本 addendum 只授权实现并冻结新 commit，不授权执行正式 Run。
