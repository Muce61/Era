## Decision

Muce approved an independent, minimum read-only receiver supplement for the 14,256 fixed T10
Group-1 receipts whose immutable payloads omit DatasetSpec `field.*` distribution digests. The
supplement may recompute those digests from the exact content-addressed objects, but it may not
change, replace, move, delete or reinterpret any T10 Manifest, Catalog, index, receipt, fragment,
object, Seal, publication record or historical PASS evidence.

The supplement must verify every affected partition before it is accepted:

- original receipt and fragment model/hash validity;
- exact object byte Hash and byte/row count;
- fragment ownership, range and semantic Hash;
- normalized partition row count and owner-date contract;
- original semantic, identity-multiset and payload-association Hashes;
- every distribution field declared by the bound DatasetSpec;
- exactly 14,256 unique partition IDs and deterministic partition ordering.

The output is a content-addressed, append-only Parquet plus Manifest under the external S2-T15
authority evidence root. Each row binds the original receipt Hash and carries its own row Hash.
The Manifest binds the fixed T10 indexes, all validated objects, this CR and the receiver
implementation Hash. Repeated generation must produce the same semantic content and Manifest.

## Gate semantics

OQ-S2-006's decision is resolved by this approval, but S2-T15 remains implementation-blocked until
the supplement is generated, verified and consumed by a fresh upstream audit with status `PASS`.
The audit must continue reporting that original T10 receipts have missing distributions and must
distinguish those immutable omissions from the accepted supplement. No Authority, Binning
Snapshot or Run ID may exist before that PASS audit and the final clean-code gate.

Any source byte drift, symlink, Hash mismatch, count mismatch, schema change, missing distribution,
duplicate partition, receiver-code drift or supplement tamper is fail-closed. It may not be
silently skipped, treated as zero or repaired inside T10.
