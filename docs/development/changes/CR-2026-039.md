## Decision

strict mypy, strict Traceability, strict governance and 678 tests. It remains available for future
genuinely exploratory work, but Plan v1.3 formal lifecycle evidence does not consume an SRP

The closure condition for `OQ-S2-009` changes. A separate whole-history availability pre-audit is
no longer required before the formal lifecycle chain. Instead, the final code and final schemas
must pass one real seven-complete-UTC-day end-to-end rehearsal covering producer serialization,
checkpoint/receipt creation, strict next-consumer read-back, reconciliation, Verify and read-only
UI projection. The existing earlier audit is useful evidence but is not this final-code rehearsal.

Passing seven days authorizes only the later human run-receipt decision. It does not prove that the
whole historical range is clean. The formal full-data Run must still validate every consumed row
and reconcile the complete range. Unknown missingness, unbound partitions, source/receipt/Hash
drift or an unreconciled count remains a terminal fail-closed condition; no skipping, imputation,
shortened window or missing-as-zero conversion is authorized.
