## Decision

Create Plan v1.5 and implement one deterministic cluster-bootstrap capability over the verified
formal T16 and T17 evidence. It publishes real-event, placebo and paired real-minus-placebo
confidence intervals plus preregistered exploratory FDR without rereading Trades or changing any
upstream result.

The implementation must preaggregate weekly sufficient statistics, use bounded vectorized
bootstrap batches, share one strict serializer across production and Verify, reject AppleDouble
files and expose Plan-v1.3-standard progress in the read-only Web UI.

## Boundary

This change does not modify the manual, Plan v1.4, T16/T17 evidence, Stage 1 or execution code. It
does not authorize a formal Run before a clean final commit receives a commit-bound approval.
T19+ and Stage 3 remain forbidden.
