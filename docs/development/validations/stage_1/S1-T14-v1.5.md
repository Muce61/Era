## Defect and correction

The scheduler loop previously used the presence of active download/build futures as its loop condition. When the last active future completed, the loop could exit before scheduling a remaining asymmetric symbol tail. A pre-fix regression reproduced this as one failure and one pass across the two symbol directions.

The corrected scheduler evaluates the complete planned archive set and distinguishes `SYMBOL_COMPLETE`, `GLOBAL_BUILD_COMPLETE`, `TEMPORARILY_IDLE`, `RECOVERY_REQUIRED`, `FAILED`, and `UNKNOWN`. Global completion now requires every planned archive to be complete with no pending or active item. A completed run is scanned idempotently and returns without invoking finalization or publication again.
