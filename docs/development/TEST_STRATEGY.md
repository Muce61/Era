# Test Strategy Template

Approved work must select applicable evidence from: unit, property, integration, replay, fault injection, schema, deterministic output, regression, and forward validation tests.

Every test record must identify the rule or contract, fixture/evidence level, command, actual result, artifacts, limitations, and validation timestamp. Historical H1/H2/H3 evidence cannot substitute for forward validation. Stage-specific test requirements are DRAFT inside the Stage and Task plans; commands remain `TO_BE_DEFINED_IN_STAGE_0` until the Stage 0 tooling task freezes real commands and a revised Task is approved.
